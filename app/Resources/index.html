Supports configuration of OpenCore setups on macOS 15 and macOS 26 Tahoe (beta), whether 1401 built them or they already existed. The current driver runtime requires macOS 15.5 or later; installation checks the payload before changing the setup. Keep the USB stick or disk OpenCore started this Mac from plugged in: 1401 changes the settings on that one. This driver is new and may not work on every PC; if your setup is not booting yet, start with the OpenCore Install Guide.

What happens

  1. Get the driver.
  2. Look before touching anything. 1401 reads your OpenCore config and lists every change it would make. Nothing is changed. (macOS asks for your password.)
  3. Install. Backs up your OpenCore config, makes exactly the changes listed, installs the driver, and adds 1401: Remove NVIDIA driver to your boot picker.
  4. Restart. If macOS says a system extension was blocked, open Privacy & Security, click Allow, and restart once more.

What 1401 is doing



Open the log folder



Update the driver


Already installed? 1401 checks for the newest NullMoth driver, downloads it, checks it against the published SHA-256, and installs it the same way as above (your OpenCore config is backed up first). Restart when it is done.


  


If something goes wrong after you restart


Restart, and in the OpenCore boot picker choose 1401: Remove NVIDIA driver, then your macOS disk. 1401 removes the driver by itself and restarts; this Mac comes back exactly as it was before the install, OpenCore config included. The screen may stay dark until that second restart.




Startup text (verbose mode)


Shows what macOS is doing while it starts instead of the Apple logo. Useful if a start hangs. Takes effect at the next restart.


 








Map your USB ports


macOS only uses 15 ports per USB controller and has no idea which ones your case actually has. 1401 watches the ports while you plug things in, then writes a map for the ports you select. Test those ports again after restarting, including USB-C in both orientations and wake from sleep. Ports that never appear in the scan still need separate discovery.

Crash report


If the NVIDIA driver ever crashes this Mac, 1401 asks the next time you log in whether to make a report. You can also make one here.


The report is a text file on your Desktop with your hardware (CPU, graphics, memory, macOS version) and what failed. 1401 takes out your name, your Mac's name, serial numbers, network addresses and file paths. Read it, then upload it on the NullMoth site if you want to. 1401 never sends anything by itself.




  


Something not working?


 1401 sends what it did, the driver's state, crash reports, OpenCore's startup logs and a numeric device/CPU map (names, serial numbers and addresses removed). You get a report ID to quote in the NullMoth Discord.


 Screen flickering or flashing? Press this while it happens: 1401 records 20 seconds of how the driver puts frames on the display and sends it with your logs.
